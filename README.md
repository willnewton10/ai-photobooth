
## Replace Background Based On Costume

Just a silly "vibecoded" photobooth for halloween parties, that uses gemini api, including nanobanana.

You have to set up your own API key for it. 

1. create an API key for google ai (set up a project, set up billing; it's not that hard, just follow the google UI)

https://aistudio.google.com/api-keys

2. download this HTML file and open it in a browser like Google Chrome

3. copy and paste your API key from 1 into the input.
